A home Wi-Fi router confesses, in one line, why it dropped the connection at the exact moment a movie reached its climax: it could not handle the suspense either.

## Run it

```sh
python3 main.py
```

The program writes the single line to `/output/entry.txt` — 125 characters, one line, no trailing newline.
